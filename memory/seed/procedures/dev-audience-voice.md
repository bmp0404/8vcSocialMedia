- **Rule:** Lead with what shipped and what it does: the command, flag, version, API or integration. For a CLI tool, show the command a reader would type; stated on 2026-10-15.
- **Rule:** Drop hype words such as "revolutionary", "game-changing", "supercharge" and "unlock". Developers reply to specifics and scroll past adjectives; stated on 2026-10-15.
- **Rule:** One announcement per post. Link the repo, docs or changelog instead of listing every feature; stated on 2026-10-15.
- **Rule:** These are house style choices, not findings from the data. Change them when review verdicts or outcomes disagree; stated on 2026-10-15.
